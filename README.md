# Arduino
Repositório onde armazeno meus códigos de exemplos no estudo de programação para o microcontrolador Atmega328p (na platafroma arduino), baseado no livro "AVR e Arduino - Tpecnicas de Projeto"

## Material de referência
Os experimentos e exercícios contidos neste repositório tomam como base o liro "AVR e Arduino - Técnicas de Projeto", de CHarles Borges de Lima e Marco V. M. Villaça. O livro pode ser encontrado e baixado gratuitamente no [blog do autor](https://borgescorporation.blogspot.com/search/label/AVR)
